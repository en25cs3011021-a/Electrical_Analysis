# Electrical_Analysis

## Project Overview
Electric Vehicle Market Performance & Insights is a data analytics project focused on exploring the electric vehicle (EV) market. It uses data visualization to understand EV sales, manufacturer performance, battery technologies, regional distribution, and customer ratings.

The project is developed using Tableau to present meaningful insights through interactive visualizations and dashboards.

## Project Objectives
- Analyze electric vehicle market trends.
- Study sales performance across manufacturers.
- Understand battery technology distribution.
- Compare EV markets across different regions.
- Analyze customer ratings and vehicle counts.
- Identify useful insights from EV market data.

## Tools & Technologies
- **Tableau:** Data visualization and dashboard development.
- **Dataset:** Electric Vehicle Market Dataset.

## Dashboard Features
- EV sales trend analysis.
- Manufacturer-wise performance.
- Battery type distribution.
- Regional market comparison.
- Customer ratings analysis.
- Interactive filters for exploring data.

## Project File
The Tableau packaged workbook is included in this repository.

**File format:** `.twbx`

The packaged workbook can be downloaded and opened using Tableau Desktop.

## How to Open the Project
1. Download the `.twbx` file from this repository.
2. Install and open Tableau Desktop.
3. Double-click the downloaded packaged workbook or open it through Tableau.
4. Explore the dashboard and its visualizations.

## Conclusion
This project demonstrates the use of Tableau for analyzing electric vehicle market data and presenting insights through interactive dashboards. It helps understand market trends, manufacturer performance, and customer preferences.
